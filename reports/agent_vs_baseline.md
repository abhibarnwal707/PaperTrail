## Reading it

On typology the agent is ahead by 1 of 24 cases, which is within what 30 cases can distinguish from noise; it takes the same action as the baseline on 28 of 30 cases; false escalations are 0 vs 0. For that it costs 4,820 tokens and 9.2 s per case against none. Where the agent can add value is the plain-English narrative, which no metric here scores, and typologies the rules cannot name (SCATTER-GATHER, STACK, BIPARTITE, RANDOM); the data shows no measurable gain on them. The typology truth is synthetic and often lists several patterns per account (a prediction counts as right if it is any of them).
